# 🎬 Netflix Clone

A full-stack Netflix-inspired web application built using HTML, CSS,
JavaScript, Node.js, Express.js, and MongoDB.

## 🚀 Features

- Netflix-inspired user interface
- User registration and login
- Password authentication
- Protected user routes
- MongoDB database integration
- REST API communication
- Responsive frontend
- Git/GitHub version control

## 🛠️ Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- Mongoose

### Tools
- Git
- GitHub
- VS Code
